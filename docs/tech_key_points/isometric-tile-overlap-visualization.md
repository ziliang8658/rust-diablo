# 等轴测瓦片重叠可视化详解

## 场景设置

- **墙壁瓦片**：世界坐标 `(2, 1)` → 屏幕位置 `(100, 50)`
- **地板瓦片**：世界坐标 `(3, 0)` → 屏幕位置 `(164, 50)`
- **瓦片尺寸**：64×32 像素（菱形）

## 关键理解点总结

### 1. 菱形瓦片的特性
- 每个瓦片是 64×32 像素的菱形
- 相邻瓦片在 X 方向间隔 64 像素
- 但由于菱形边缘倾斜，会部分重叠

### 2. 重叠区域
- 重叠发生在相邻瓦片的边缘
- 墙壁右边缘 (X: 132-164) 与地板左边缘重叠
- 重叠区域大约 32 像素宽

### 3. 深度排序
- 深度由世界坐标的 Y 值决定
- Y 值越大 = 越靠前 = 应该后渲染
- 墙壁 (Y=1) 在地板 (Y=0) 前方

### 4. 渲染顺序
- **错误顺序**：先墙壁后地板 → 地板覆盖墙壁 → 精灵穿透
- **正确顺序**：先地板后墙壁 → 墙壁覆盖地板 → 精灵被遮挡
