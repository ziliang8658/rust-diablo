# Sprites Directory

这个目录包含游戏使用的所有精灵图资源。

## 玩家精灵图 (player.png)

### 当前版本：猴子精灵图

**规格**：
- 尺寸：256x64 像素
- 格式：PNG（RGBA，支持透明）
- 帧数：4 帧（水平排列）
- 每帧大小：64x64 像素

**帧布局**：
```
[帧1: 静止猴子] [帧2: 猴子+云朵1] [帧3: 猴子+云朵2] [帧4: 猴子+云朵3]
    0-63           64-127           128-191          192-255
```

**动画状态**：
- **Idle（静止）**：使用帧 1 - 站立的猴子
- **Walk（移动）**：循环播放帧 2→3→4→3 - 猴子乘坐云朵

### 生成方法

使用 Python 脚本自动生成：

```bash
cd rust-diablo/assets
pip install pillow  # 如果还没有安装
python create_monkey_sprite.py
```

脚本会生成 `sprites/player.png` 文件。

现在已替换为更丰富的猴子动画精灵图。

## 注意事项

1. **文件格式**：所有精灵图必须是 PNG 格式，支持透明通道
2. **文件路径**：精灵图必须放在 `assets/sprites/` 目录下
3. **加载失败**：如果精灵图加载失败，游戏会自动回退到使用颜色矩形显示
4. **精灵表**：玩家精灵图使用精灵表（sprite sheet）格式，包含多个动画帧

## 自定义精灵图

如果你想创建自己的精灵图：

1. **玩家精灵图**：
   - 修改 `create_monkey_sprite.py` 脚本
   - 或手动创建 256x64 像素的 PNG 图片
   - 确保每帧是 64x64 像素

2. **瓦片精灵图**：
   - 创建 32x32 像素的 PNG 图片
   - 命名格式：`tile_<类型>.png`
   - 在 `world/collision.rs` 中添加对应的 `sprite_id()`

3. **动画帧**：
   - 在 `entity/mod.rs::create_player()` 中更新动画帧坐标
   - 确保帧坐标与精灵表中的位置匹配
